Icebreaker
Name an interface you used today that annoyed you.
Tell the person next to you. What exactly got in the way?
Pairs first, then take three or four answers from the room. Push for the specific thing: a button that was hard to find, text too small, an error that didn't say what was wrong. Those are the things this course gives words for: colour, type, layout, input, accessibility.
The course

What this course is about

Design

Designing graphical user interfaces

Looking at interfaces closely, sketching alternatives, and making considered design decisions.

Build

Building them for the screen

Turning those designs into real pages with HTML and CSS that work in a browser.

ColourTypeContentIconsLayoutInteractionAccessibilityMotion
The course runs on two tracks that meet every week: design (Thursdays) and building (Fridays). The topics run from colour and type through layout and interaction to accessibility. Each Thursday topic gets a matching Friday in code.
The course

Learning outcomes

1

Analyse interface designs using the theory introduced in the course

2

Use sketching to explore many different design directions

3

Design for screens using appropriate design principles

4

Create W3C-validated, semantically correct HTML markup and CSS

Walk through the four. 1–3 are mostly Thursdays; 4 is Fridays. Each one maps to an assessment, which comes up in a few slides. "W3C-validated" means it passes the validator at validator.w3.org; we'll use it from the first Friday.
