The Pane mark and lockup as outlined SVG (the word is drawn as shapes, so no font is needed). Use them through `<img>`; SVG shown that way cannot inherit colour, so choose the file for the ground.

- `pane-mark-color.svg`, `pane-lockup-color.svg`: teal and plum with `#1E1530` ink, for `surface-100` and light grounds.
- `pane-mark-reverse.svg`, `pane-lockup-reverse.svg`: the same with `#F5F2F8` outlines and word, for dark grounds.
- `pane-mark-mono.svg`, `pane-lockup-mono.svg`: one ink colour (`#1E1530`), for single-colour print and stamps.

Keep clear space of half the mark's height. Minimum size: mark 24 px, lockup 96 px wide.
