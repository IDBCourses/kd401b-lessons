# How Pane speaks to Malmö University

Pane is a distant relative of the university's graphic manual, not a copy. It borrows ideas, not assets: no MAU colours, logo, frames or imagery are reused, so it is clear to a student which is which, and Pane never competes with the university as sender. When a deck needs the university's logo, use the official files and the clear space in the manual.

| In the MAU manual | In Pane |
| --- | --- |
| Futura headlines, Sabon body text | Jost headlines, Source Serif 4 body text: the same sans-and-serif pairing, in fonts every student can install |
| Signal red with 23 secondary shades | Lilac paper and ink with three accents (plum, teal, pink), soft tints and an 80s outdoor-jacket colourblock feel |
| Dynamic frames: boxes behind headline lines, offset and overlapping, two to four lines | Pane frames: the same idea of a box per line, with a fixed stagger and one frame per slide |
| Halftone dots and duotone collage | A plain dot grid at a 32 px pitch, standing for pixels |
| Logo with clear space and a fixed set of variants | Logo of two offset panes with clear space and colour, reverse and mono variants |
| Templates made to WCAG, Arial and Times New Roman as fall-backs | Contrast checked per pair in three themes, with Futura, Georgia and Consolas as fall-backs |
| Photography of people, places and Malmö | Screenshots and wireframes of interfaces, framed as evidence |

What stays the same: a clear sender, a type pairing that is easy to read, headlines that are large and plain, one idea at a time, and accessibility treated as a requirement. If a course slide is shown with the university's identity beside it, the two should look related but never confusable.
