A bordered monospace block for code, token values and commands, on `surface-300`.

**You provide** the code as a string child, and optionally `label` (a file name) and `size` (`ui` or `slide`).

- Use `size="slide"` (32 px) on slides; keep each line short enough to fit without scrolling.
- The block is keyboard-focusable so long lines can be scrolled.
- Do not colour-code syntax by hue alone.
