A set of tabs that switch between panels of related content.

**You provide** `tabs` as `{id,label,content}`, and optionally `defaultId` and a group `label`.

- Arrow keys, Home and End move focus and selection; only the selected tab is in the tab order.
- Selected tab: bold label, teal bar and `plum-tint` ground.
- Keep labels to one or two words; use for peer content, not for steps.
