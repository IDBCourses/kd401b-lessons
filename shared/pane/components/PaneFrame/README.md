A headline set as one coloured box per line, each line slightly indented and overlapping the last. It is the system's signature and is used once per slide.

**You provide** `lines` (an array, or a string with `|` between lines) or children, and optionally `tone` (`plum`, `teal`, `pink`, `ink`, `paper`), `size` in px (default 96), `as` (`h1`, `h2` or `p`) and `stagger`.

- Write the headline as one sentence in sentence case, two to four lines. Lines are visual only and read as one heading.
- Each tone carries its own text colour, so contrast holds in every theme.
- Use `plum` on paper, dark and teal slides; `ink` on plum slides; `paper` on teal and pink slides. Each tone carries its own text colour.
- Do not put two frames on one slide, do not add more than four lines, and do not set the text in a different colour.
