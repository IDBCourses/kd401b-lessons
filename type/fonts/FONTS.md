# Fonts used only by this lecture

- **Roboto Flex** (variable: opsz, wght, GRAD, wdth, slnt and parametric axes), from
  [google/fonts](https://github.com/google/fonts/tree/main/ofl/robotoflex). Subset to Latin and
  converted to WOFF2 with fontTools (`pyftsubset`, all layout features kept). Licence: SIL Open Font
  License 1.1, see `RobotoFlex-OFL.txt`.

Used by the variable font, type scale, reading mode and through-line slides. Pane's own fonts stay in
`shared/pane/fonts/`.
